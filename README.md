# GAMR1530 Coursework 2026

Ray-Tracer using HTML, Javascript and CSS.
Made by Denis Saracev - P2922929

How to run the code:

1. Open VSCode;
2. Click "Extensions";
3. Search "Live Server";
4. Press Install;
5. When its done installing, bottom right of the screen, click "Go Live", and it should work.
   I have a screenshot in the 'img' folder that shows of it working on my end.

A couple things to know when on the website:

1. When you press the "Render Image" button, it takes some time to render an image, it isn't broken.
2. If you scroll down, you will see settings you can tinker around with.
3. When you use the settings, and change something, remember to press "Render Image" to update the image.

Additional things I want to mention:
img folder:
gradient.png - is the logo of the website.
screenshotOfProof.png - is the proof that I could run the website on my laptop, using the "How to run the code" guide.

JS folder:
main.js - The main program which runs everything.
ray.js - Calculates the point in space of a ray.
rayCastResult.js - Result of casting a ray into a scene.
spheres.js - Calculates ray intersection with spheres.
vector.js - All the vector calculations are stored here.

24FramesSong.mp3 - Is a song that I entirely made on my own in 2025 that I decided to re-use for this project.
index.html - The HTML that runs the program.
style.css - Holds all information about text colour, buttons and sliders.
